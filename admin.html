Datos del repositorio
¿Cómo creo el token?
  1. Abre github.com/settings/personal-access-tokens/new.
  2. Ponle un nombre (por ejemplo «Panel portafolio») y una fecha de vencimiento.
  3. En Repository access elige Only select repositories y marca solo Portafolio-Giovanny.
  4. En Permissions › Repository permissions busca Contents y ponlo en Read and write.
  5. Toca Generate token, cópialo y pégalo arriba.
